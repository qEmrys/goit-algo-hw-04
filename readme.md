# Порівняльний аналіз алгоритмів сортування

## Результати

| Розмір масиву | Merge Sort  | Insertion Sort | Timsort     |
|---------------|-------------|----------------|-------------|
| 100           | 0.000102 с  | 0.000124 с     | 0.000003 с  |
| 1000          | 0.001836 с  | 0.015071 с     | 0.000069 с  |
| 5000          | 0.008536 с  | 0.416053 с     | 0.000548 с  |
| 10000         | 0.017664 с  | 1.593327 с     | 0.001248 с  |

## Висновки

Insertion Sort (O(n²)) різко сповільнюється зі зростанням масиву і на 10 000 елементів у 90 разів повільніший за Merge Sort.

Merge Sort (O(n log n)) стабільний, але написаний на чистому Python.

Timsort — найшвидший у всіх випадках, оскільки поєднує переваги обох алгоритмів і реалізований на рівні C.
